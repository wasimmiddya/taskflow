# TaskFlow
Task Flow is a project management tool specifically designed for software projects. It streamlines daily task assignments, status tracking, and team communication.

### **_<u>Key Features:</u>_**
1. **Basic & RBAC authentication:**
    1. Login & Sign-up.
    2. Permission based access.
    3. There are three types of Role:
        1. Admin
        2. Owner (Project Manager)
        3. User (any employee or assistant manager, etc.)


2. **Dynamic Task Allocation:** Easily assign daily tickets and manage developer bandwidth to prevent burnout.
3. **Real-Time Status Tracking:** Gain instant visibility into the development pipeline with Kanban boards and automated progress reports.
4. **Integrated Communication:** Reduce "meeting fatigue" by keeping technical discussions and feedback directly within the relevant task cards.
5. **Sprint Planning:** Organizes backlogs into manageable two-week cycles.
6. **Bug Tracking:** Centralizes issue reporting to ensure no critical fix is missed.
7. **_API Integration:_** _Connects directly with GitHub or GitLab to sync code commits with tasks(future scope)._
8. **Workflow:** Task workflow visualization.
